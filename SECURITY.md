# Security Policy

Pearcleaner searches for and removes files, installs a privileged helper, and
includes update and deep-link functionality. Please report security defects
carefully so users are not exposed before a fix is available.

## Supported Versions

Security fixes are made for the latest release published by this maintained
fork. Older fork releases and upstream releases may not receive the same fixes.
Before reporting, reproduce against the latest fork release when it is safe to
do so.

## Reporting a Vulnerability

This repository does not currently have GitHub private vulnerability reporting
enabled. Do not include exploit details, sensitive paths, credentials, personal
data, or proof-of-concept code in a public issue.

Use the
[security contact template](https://github.com/lukeskyscraper8/Pearcleaner/issues/new?template=security.md)
to request a private reporting channel. Include only:

- the affected fork version and build number;
- the affected component, such as file removal, privileged helper, updater,
  deep links, or Finder extension;
- a non-sensitive impact summary; and
- confirmation that you have not published technical details elsewhere.

The maintainer can then arrange a private channel for the complete report.
Normal bugs without security impact should use the
[bug report template](https://github.com/lukeskyscraper8/Pearcleaner/issues/new?template=bug.md).

## Coordinated Disclosure

Allow time for the report to be reproduced and, where appropriate, for a fixed
release to reach users before publishing technical details. This project does
not publish a guaranteed response time or vulnerability-reward programme.
